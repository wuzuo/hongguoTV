# 果映 TV 界面材质与主题

TV 版界面统一使用新拟态（Neumorphism / Soft UI）：一块材质、三个台阶、柔光表达层次。
本文说明已实现的规则与边界，供后续改动保持一致的观感。

## 材质

全站只有一块同色相材质，层次靠明度与柔光；唯一例外是卡片焦点外沿的一圈强调色细线（见下）。

| 状态 | 底板 | 文字 |
| --- | --- | --- |
| 常态 | 凸起面（右下深投影 + 左上高光） | 主题正文色 |
| 选中 / 已开启 | 凹陷面（按进去） | 强调色 |
| 焦点 | 最亮的亮面 + 光晕 + 轻微放大 | 近黑字 |
| 主操作 | 常亮的亮面（一屏只有一个） | 近黑字 |

- 焦点放大：卡片 1.02–1.03，按钮 1.04–1.05。放大幅度受限，滚动容器不会切掉焦点。
- **卡片焦点不用亮面**：卡片里是图片和浅色剧名，深色主题下亮面接近纯白，剧名会消失；
  卡片焦点改为「抬一档 + 更深的柔光 + 光晕 + 剧名转亮 + 2dp 强调色描边」，只有按钮、导航项、设置项用亮面。
  描边由 `TvStyle.cardFocus()` 画在 `View.foreground` 上（API 23 起可用），海报占掉卡片大部分面积时仍能看清焦点。
- 强调色只做线与小色块（进度条、名次星标、当前项文字），不画彩色选框。

柔光的几何约定：控件的内边距等于柔光带宽度（常规 6dp，弹窗 10dp），
投影全部画在控件自己的内边距里，因此滚动容器可以正常裁剪，不需要父级「不裁剪」。
按钮高度 = 底板高度 + 两侧柔光带（常规 40+12=52dp，主操作 56+12=68dp）。

## 主题

设置 → 界面主题提供 14 套材质，默认「深邃暗调」（电视多在暗环境观看）：
经典浅灰、优雅奶白、深邃暗调、高级柔冷、瓷白、月岩灰、象牙沙、银鼠尾草、蓝雾、
香槟丝绸、灰雾玫瑰、苍岩橄榄、石墨、午夜蓝。

一套主题只写底色、高光、投影、亮面、文字基色、强调色与深浅属性，其余档位按固定比例派生
（凸起面 = 底色→高光 45%，抬升面 72%，凹陷面 = 底色→投影 45%，深凹槽 72%）。
新增主题只需在枚举里加一行，组件代码不用改。

- 偏好保存在独立的 SharedPreferences `native-theme-v1`，不写入本机 Library，也不参与手机备份合并：
  配色不应跟着观看记录在设备之间搬家。
- 切换主题后只重建当前页面，不重启 Activity；账户、本机记录与播放偏好不重新加载。
- 播放界面压在视频画面上，固定暖白文字 + 黑压暗层 + 半透明黑底按钮，不随主题切换。

## 兼容与性能

- 柔光不用 `RenderEffect`（需 API 31），改为把「投影 + 高光」预渲染成半分辨率位图并做 LRU 缓存
  （上限 48 项 / 8 MiB，单张超过 3 MiB 时退回纯色），每帧只画一张已经模糊好的图，最低支持 API 23。
- 低内存设备在启动时关闭焦点缩放动画，并把柔光紧致度降到 80%；层次不变。
- 系统 `AlertDialog` 不逐个重写内部列表，只通过 `decorateDialog()` 换成柔光外壳与主题文字色。

## 代码位置

- `app/src/main/kotlin/com/hongguotv/nativeapp/TvStyle.kt`：设计令牌、形状工厂、焦点反馈、弹窗外壳。
- `app/src/main/kotlin/com/hongguotv/nativeapp/TvTheme.kt`：14 套主题与偏好存储。
- `app/src/main/kotlin/com/hongguotv/nativeapp/TvSoft.kt`：柔光绘制与位图缓存。
- 各页面只调用 `TvStyle.soft / well / card / focus` 与令牌，不直接写死颜色和圆角。
